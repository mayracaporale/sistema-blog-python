# Sistema de Blog en Python

## Descripción
Proyecto desarrollado en Python para administrar publicaciones de un blog utilizando Programación Orientada a Objetos (POO).

## Funcionalidades
- Listar publicaciones.
- Buscar publicaciones por título.
- Filtrar publicaciones por etiqueta.
- Crear nuevas publicaciones.
- Validar los datos de las publicaciones.
- Guardar y cargar información mediante archivos JSON.

## Estructura del proyecto
- `main.py`: programa principal.
- `posts.json`: almacenamiento de publicaciones.
- `blog/__init__.py`: inicializador del paquete.
- `blog/modelos.py`: clases Autor, Post y Blog.
- `blog/datos.py`: carga y guardado de datos JSON.
- `blog/menu.py`: menú de opciones.

## Tecnologías utilizadas
- Python.
- Programación Orientada a Objetos (POO).
- JSON.

## Ejecución
Ejecutar el archivo principal desde la terminal:


python main.py


## Objetivo
Aplicar los conceptos de POO, validación de datos, organización modular y persistencia de información en un proyecto práctico.
